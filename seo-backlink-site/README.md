# abcpoint.online — বাংলা SEO ও Backlink Guide

বাংলায় SEO শেখার দুইটি প্রকাশযোগ্য গাইড: Backlink Guide এবং SEO-এর পূর্ণাঙ্গ পরিচিতি। SEO terms English-এ, ব্যাখ্যা সহজ বাংলায়।

## Vercel static site

এই directory-র static files Vercel project root হিসেবে deploy করুন। Build command লাগে না। Preferred site URL `https://www.abcpoint.online/`; apex domain `abcpoint.online` এটি redirect করে। `sitemap.xml` ও `robots.txt`-এ www host ব্যবহৃত হয়েছে।

## Pages

- `index.html` — Backlink Guide; ২০০+ প্রশ্নোত্তরসহ
- `seo-guide.html` — SEO-এর ধরন, On-page, Off-page, Technical SEO, research, infrastructure, safe promotion ও FAQ
- `sitemap.xml` / `robots.txt`

## SEO features

Unique titles/descriptions, canonical URLs, Open Graph/Twitter metadata, Article JSON-LD, semantic headings, internal links, image alt text, sitemap ও robots rules। Search engine indexing বা ranking নিশ্চিত নয়।
